# Cairo

Bundled variable Cairo font from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/cairo

Source: `Cairo[slnt,wght].ttf`; downloaded 2026-10-13. SHA-256:
`667c987182391c91f4e57a2f455b1794fb5e3ee6ca4ef3383e86bb690fa9c964`.

Used only for the Home Arabic passage, with body weight 500 and heading weight
700. The font is local; no runtime font service is used. See the unmodified
