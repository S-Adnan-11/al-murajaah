# Changelog

Notable changes in published releases. Downloads and checksums are available on
[GitHub Releases](https://github.com/S-Adnan-11/al-murajaah/releases).

## 1.0.1 — 2026-10-16

Android build `1.0.1+36`.

- Stream the complete 114-surah Zarami/Hafs catalogue or download recordings
  with size and SHA-256 verification for offline listening.
- Save A–B passages and repeat them with playback speed, gaps and sleep controls.
  Browsing other recordings leaves the active session playing.
- Track listening activity, daily goals and streaks locally, and export or
  preview/import metadata backups.
- Use Light, Dark or System appearance and send reviewed text feedback to the
  public feedback tracker.

This build uses the project's production signing certificate. Earlier private
test builds use a different certificate and need a backup-and-import migration
instead of an ordinary update. Follow the
[installation and migration instructions](README.md#install-on-android) before
removing an old installation; metadata backups do not include audio downloads.

Known limitations: crackling has been reported on Redmi 12C, broader Android
device testing is still needed, and iOS builds and device behaviour remain
unverified.
